Mesa 26.2.6 Release Notes / 2026-10-28
======================================

Mesa 26.2.6 is a bug fix release which fixes bugs found since the 26.2.5 release.

Mesa 26.2.6 implements the OpenGL 4.6 API, but the version reported by
glGetString(GL_VERSION) or glGetIntegerv(GL_MAJOR_VERSION) /
glGetIntegerv(GL_MINOR_VERSION) depends on the particular driver being used.
Some drivers don't support all the features required in OpenGL 4.6. OpenGL
4.6 is **only** available if requested at context creation.
Compatibility contexts may report a lower version depending on each driver.

Mesa 26.2.6 implements the OpenCL 3.1 API, but the version reported by
the CL_DEVICE_VERSION, CL_DEVICE_NUMERIC_VERSION and CL_DEVICE_OPENCL_C_ALL_VERSIONS
clGetDeviceInfo queries depends on the particular driver being used.

Mesa 26.2.6 implements the Vulkan 1.4 API, but the version reported by
the apiVersion property of the VkPhysicalDeviceProperties struct
depends on the particular driver being used.

- GPULostDevice on 6800 XT (mesa-26.0.X)
- Intel Meteor Lake: Unigine Heaven and Valley trigger GPU hangs with Mesa 26.2.0–26.2.4; work with 26.1.8
- Witcher 3 Remastered - Graphical/visual bug that act like an overlay
- [Turnip/A650] Hangs in several several games due to some missing shader(?) workaround
- d3d12 (WSL2, NVIDIA RTX 5090): self-deadlock in d3d12_bo_new(), reclaim under pb_slab manager mutex hangs RPCS3 on compressed texture upload
- freedreno: garbled text rendered by pdf.js on snapdragon x1 elite
- kopper: non-dmabuf sw texture update is broken
- lavapipe: maintenance8 depth/stencil <-> color vkCmdCopyImage copies only sample 0 of multisampled D32_SFLOAT_S8_UINT and D24_UNORM_S8_UINT images
- lavapipe: new RT fails
- v3dv: gpu hang when an inline uniform block comes before a sampled image
